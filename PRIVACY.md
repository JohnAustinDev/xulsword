# xulsword Privacy Policy

Effective date: November 6, 2026

This policy covers the xulsword desktop application, also called MK,
including copies installed from the Microsoft Store and from GitHub.

xulsword has no user accounts, advertising or analytics, and does not sell or
share personal information. Your notes, bookmarks, settings and installed
texts are stored only on your own computer.

## Internet use needs your permission

xulsword works without the Internet. The first time it needs the Internet,
for example to download a Bible, it asks for your permission. Nothing
described below is sent or downloaded unless you answer "Yes".

If you also check "Remember my choice", xulsword uses the Internet when needed
without asking again. There is currently no setting to undo this. To be asked
again, delete the `preferences` folder in xulsword's profile folder (on
Windows, `%APPDATA%\MK\preferences`). Doing so also resets your other settings.

## What is sent, and to whom

### Downloading texts and audio

When you open the Module Manager, or download or play a Bible, commentary,
dictionary, book or audio recording, xulsword connects to the module
repositories that are listed there. These are run by the Institute for Bible
Translation (ftp.ibt.org.ru), CrossWire Bible Society (crosswire.org) and
others, and you can add your own. Like any server, they see your IP address and
which files you download, and they may keep it in their logs under their own
privacy policies.

Some texts name a web font, which xulsword then downloads from the address the
text gives.

### Crash reports

If xulsword crashes, a crash report is saved on your computer. It is also sent
to xulsword's crash report server at ibtrussia.org, but only if you have
allowed Internet use and checked "Remember my choice".

A crash report contains:

- a memory snapshot of the part of the app that crashed (a "minidump"), which
  may hold fragments of what was on screen or in use, such as text being read
  or file names
- the app version, operating system and display language, and which window
  crashed
- a random ID that the crash reporter creates the first time the app runs,
  and that is not linked to your name
- your IP address, which the server records when the report arrives

Crash reports are used only to find and fix bugs. They are not shared with
anyone else. A one-line summary of each report, with the IP address, is kept in
the server's log.

### Error reports

If xulsword detects an error, it may show a message with a "Report" button.
Only if you click it, your web browser opens a new issue on GitHub with the
error details filled in. You can read and change it before submitting, and
nothing is sent unless you submit it. GitHub's privacy policy applies.

### Links

Web links in texts open in your web browser only when you click them.

### Updates

Microsoft Store copies are updated by the Microsoft Store, under Microsoft's
privacy policy. Copies installed from GitHub check GitHub for updates when
Internet use is allowed, which sends GitHub your IP address and the app
version.

## Children

xulsword does not collect personal information from anyone.
